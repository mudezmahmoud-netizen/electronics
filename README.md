# Techstore - Electronics Product Showcase

## Project Overview

Techstore is a modern and responsive electronics e-commerce product showcase website. 
The project is designed to provide users with a clean and engaging shopping experience 
while displaying different technology products.

The website focuses on responsive CSS design, accessibility, visual hierarchy, 
micro-interactions, and a consistent design system.

## Project Goals

The main goals of this project are to:

- Create a modern electronics shopping interface
- Display multiple technology products
- Create a responsive layout for desktop and mobile devices
- Use CSS for layouts, animations, transitions, and interactions
- Provide an accessible and user-friendly interface
- Create a consistent color, typography, and spacing system
- Optimize the website for performance

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- CSS Media Queries
- CSS Transitions and Animations
- Figma for UI/UX design
- Git and GitHub for version control

## Important Project Constraint

This project is created **without JavaScript**.

All visual interactions and UI effects are implemented using HTML and CSS.

## Features

### 1. Responsive Design

The website is designed to work on:

- Desktop computers
- Tablets
- Mobile phones

CSS media queries are used to adjust the layout for different screen sizes.

### 2. Navigation

The website includes navigation links such as:

- Home
- Deals
- Products
- Contact
- Shopping Cart

### 3. Hero Section

The homepage includes a hero section with the message:

> Upgrade Your Digital Life

It also contains a short description and a "Shop Now" call-to-action button.

### 4. Product Showcase

The website displays multiple electronics products, including products such as:

- Laptops
- Smartphones
- Headphones
- Smartwatches
- Other technology accessories

Each product includes relevant information such as its name, image, price, and rating.

### 5. CSS Micro-interactions

CSS transitions and hover effects are used to improve the user experience.

Examples include:

- Button hover effects
- Product card animations
- Image scaling
- Smooth transitions
- Loading animations

### 6. Dark Mode

CSS custom properties are used to support a dark-mode theme while maintaining consistent colors throughout the website.

### 7. Accessibility

The website considers accessibility through:

- Sufficient color contrast
- Descriptive image alt text
- Clear typography
- Keyboard-friendly controls
- Semantic HTML elements
- Accessible navigation

### 8. Print Stylesheet

A print stylesheet is included to make product information readable when the page is printed.

## Design System

### Colors

| Element | Color |
|---|---|
| Primary Blue | #155EEF |
| Button Blue | #1683FF |
| Background | #F5F5F5 |
| White | #FFFFFF |
| Main Text | #111111 |
| Secondary Text | #555555 |

### Typography

The design uses a simple and readable typography hierarchy.

- Large headings: 48px - 64px
- Section headings: 32px - 40px
- Body text: 16px - 18px
- Small text: 14px

Responsive font sizing is used where appropriate.

### Spacing

The design uses consistent spacing between:

- Sections
- Product cards
- Buttons
- Navigation items
- Images
- Text elements

## Figma Design

The Hi-Fi design includes:

- Homepage

- Hero section
- Product showcase
- Product cards
- Call-to-action buttons
- Footer
- Mobile layout
